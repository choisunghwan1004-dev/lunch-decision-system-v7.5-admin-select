🌏 국가 등록

국가를 직접 입력하지 않고 목록에서 선택해 추가합니다. 이미 등록된 국가는 중복 등록되지 않습니다.

📍 지역 등록

먼저 국가를 선택하면 해당 국가의 지역만 표시됩니다.

🏙️ 도시 등록

국가 → 지역을 선택하면 등록 가능한 대표 도시가 표시됩니다.

🏘️ 상권 등록

국가 → 지역 → 도시를 선택한 뒤 대표 상권을 선택합니다.

🍚 음식점 등록

국가 → 지역 → 도시 → 상권을 모두 선택합니다. ID를 직접 입력하지 않습니다.

🗺 실제 여행 장소
